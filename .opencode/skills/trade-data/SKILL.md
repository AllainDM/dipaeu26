## Что делаю

Добавляю новый ход в данные торговли: цены (`costData`) и/или количество (`countData`), кнопку в `trade.html`, и запись в `log.html`.

## Как использовать

Когда задача — добавить данные по торговле за новый ход (цены, количество), выполни:

### 0. Получить данные

Данные для нового хода находятся в изображениях:
- **Цены**: `img/trade/cost/<N>cost.jpg`
- **Количество**: `img/trade/count/<N>count.png`

Прочитай изображение с помощью инструмента `Read` и переведи табличные данные в текстовый формат. Изображение содержит таблицу 36 товаров × 8 ТЦ.

### 1. Данные товаров

Цены — массив 36 товаров × 8 торговых центров. Порядок товаров:

```
Алкоголь, Бумага, Благовония, Волокно, Х/оружие, Доспехи, Др/камни, Древесина,
Железо, Золото, Инструмент, Краски, Кони, Кожа, Лекарства, Медь, Мех, Мрамор,
Оружие, П/п, Пряности, Порох, Пушки, Рабы, Сахар, Свинец, Серебро, Соль,
Стекло, Табак, Ткани, ТНП, Украшения, Уголь, Шёлк, Чай
```

Порядок ТЦ: `Новгород, Крым, Ганза, Фландрия, Севилья, Египет, Ормуз, Венеция`

### 2. Добавить блок в `trade-data.js`

В `costData` (и/или `countData`) добавить блок:

```js
N: {
    markets: ["Новгород", "Крым", "Ганза", "Фландрия", "Севилья", "Египет", "Ормуз", "Венеция"],
    goods: [
        ["Алкоголь",      3,   3,   3,   2,   3,   3,   3,   0.5],
        // ... 36 строк
    ]
},
```

### 3. Добавить кнопку в `trade.html`

В массив `turns` добавить:

```js
{num: N, cost: true/false, count: true/false}
```

### 4. Обновить `log.html`

Добавить запись в лог изменений.

## Важно

- Разделитель дробной части — точка (1.5, а не 1,5)
- Следовать форматированию существующих блоков
- Имена товаров должны совпадать с эталонным списком выше
